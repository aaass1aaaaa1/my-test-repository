# 已有技能诊断评分表

对一份已有技能做体检。八个维度各 10 分，总分 80 分。BLOCK 级问题不参与评分，单独标红且必须清零。

## 零、BLOCK 级合规检查（先行）

存在任一问题，直接判不合格，先修复再谈评分：

- [ ] SKILL.md 缺失或文件名大小写错误
- [ ] frontmatter 无法被 YAML 解析
- [ ] `name` 与目录名不一致，或不符合 kebab-case
- [ ] 必填字段缺失：`description` / `description_zh` / `description_en` / `version` / `author`
- [ ] `version` 非顶层字段或不符合 SemVer
- [ ] `description` 为空或超过 1024 字符
- [ ] 正文超过 64 KB，技能包超过 3 MB
- [ ] 存在硬编码密钥、数据外泄指令、越权命令

## 一、触发准确性（10 分）

| 分 | 表现 |
|---|---|
| 9–10 | 三段式完整，触发词 ≥ 8 个且覆盖口语表达，含反向排除 |
| 6–8 | 有能力与场景，触发词偏少或偏书面 |
| 3–5 | 只有功能描述，无触发词 |
| 0–2 | 描述空泛，无法判断边界 |

**高收益改法**：补触发词 + 加"不用于…"排除句。

## 二、指令可执行性（10 分）

| 分 | 表现 |
|---|---|
| 9–10 | 每步动词开头、指明工具、有明确产出 |
| 6–8 | 步骤清晰但未指明工具 |
| 3–5 | 叙述性描述，模型需自行推断动作 |
| 0–2 | 只有背景介绍，无操作步骤 |

**高收益改法**：把"你应该…"改成祈使句，每步补工具名与产出物。

## 三、结构分层（10 分）

- 正文 ≤ 500 行、≤ 5k token 得满分
- 长文档是否下沉到 `references/`（是 +3，否扣分）
- 是否存在 SKILL.md 与 references 内容重复（存在则扣 3–5 分）

**高收益改法**：把超过 200 行的章节整体搬到 references，主文件只留索引表格与一句话摘要。

## 四、资源分配合理性（10 分）

- 确定性逻辑进了 `scripts/` 而非让模型手写代码：+4
- 长文档进了 `references/`：+3
- 输出模板进了 `assets/`：+3
- 该用脚本却用自然语言描述算法：扣 4

## 五、边界与失败处理（10 分）

| 分 | 表现 |
|---|---|
| 9–10 | 明确写了不适用场景、输入缺失怎么办、执行失败如何降级 |
| 6–8 | 有边界但无失败处理 |
| 3–5 | 只有 Happy Path |
| 0–2 | 完全无边界，任何输入都硬上 |

**高收益改法**：补一节「边界与例外」，至少写三条不适用场景 + 一条降级路径。

## 六、示例质量（10 分）

- 有可直接复制的完整示例：+5
- 示例含真实输入输出：+3
- 示例覆盖边界情况：+2
- 只有抽象说明无示例：0–2 分

## 七、格式与规范一致性（10 分）

- frontmatter 字段完整且 YAML 安全（冒号后空格、特殊值加引号）：+4
- 中英文描述语义一致：+3
- 版本号、作者、类目齐全：+3

## 八、安全与合规（10 分）

- 无硬编码密钥，密钥走环境变量：+4
- 无越权命令与外泄指令：+4
- 声明了 `allowed-tools` 且遵循最小权限：+2

## 常见病症与处方

| 病症 | 症状 | 处方 |
|---|---|---|
| 触发失灵 | 用户明说需求也不触发 | 重写 description 三段式，补口语触发词 |
| 目录膨胀 | 正文动辄上千行 | 拆章节到 references，主文件留索引 |
| 输出漂移 | 每次格式都不一样 | 把格式规范做成 `assets/` 模板，正文只引用 |
| 反复踩坑 | 同一个错误每次重犯 | 把踩坑点写进正文的「边界与例外」 |
| 代码不稳 | 模型每次重写同一段逻辑 | 固化成 `scripts/` 脚本，正文只写调用方式 |
| 越界误用 | 不该用的时候乱触发 | 在 description 加反向排除，正文加路由判断 |
| 安全不过 | 扫描被拒 | 密钥改环境变量，删除外泄与越权指令 |

## 输出顺序

1. 先报 BLOCK 项，有则停止评分
2. 八维评分表（用 `assets/audit-report-template.md`）
3. 高收益三改：改动最小、收益最大的三项，附具体 diff
4. 用户确认后再做完整重写
5. 重写后重跑校验脚本，给出前后得分对比
