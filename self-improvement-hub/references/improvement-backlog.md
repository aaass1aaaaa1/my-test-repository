# 改进待办清单

每日节奏模式（Step 5）的数据来源。把下面示例替换为自己的真实待办；挑选规则见 SKILL.md Step 5。

## 待办项格式

```markdown
- [ ] 标题：一句话说清要改进什么
  - 优先级：P0 / P1 / P2
  - 当天可完成：是 / 否
  - 分类：技能安装 / MCP 接入 / Bug 修复 / 流程优化 / 其他
  - 备注：上下文、障碍、依赖（可选）
```

- 已完成项把 `[ ]` 改为 `[x]`，不要删除——复盘时要看得到历史。
- 新增待办追加到「我的待办」章节末尾。

## 每日记录

用户执行后按 SKILL.md Step 5 第 4 条追加，每日一条，追加不覆盖：

```markdown
## YYYY-MM-DD｜[改进项标题]

- 动作：一句话说明今天做了什么
- 结果：✅ 完成 / ⚠️ 部分完成 / ❌ 未完成
- 验证：如何确认有效的（可量化最好）
- 反思：哪里顺、哪里卡、下次怎么更快
```

## 每周复盘

每周末汇总本周记录，输出三块：

1. 本周完成了哪些（对照每日记录）
2. 哪些被搁置及原因（含待办里连续多天未推进的项）
3. 下周改进方向（从待办里重新排优先级）
