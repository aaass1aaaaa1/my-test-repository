# 置信度门控与降级规则

目的：信息不足时不编造，把「不确定」显式标出来。

## `[需核实]` 占位符

出现以下场景时输出 `[需核实:字段]`，禁止编造：

| 场景 | 占位示例 |
|---|---|
| 技能版本未知 | `[需核实:技能版本号]` |
| 依赖项不明确 | `[需核实:依赖项列表]` |
| 安装命令不确定 | `[需核实:安装命令]` |
| README / 用法未知 | `[需核实:用法示例]` |

## 置信度三级

| 置信度 | 标识 | 行为 |
|---|---|---|
| 高（≥90%） | 直接给结论 | 名称、版本、安装凭证来自本次真实检索返回 |
| 中（60–89%） | 建议 + 标注 | 推荐组合来自经验判断，需用户确认后再执行 |
| 低（<60%） | 占位符 + 提问 | 信息不完整或来源不可靠，问一次，不猜 |

## 本技能的判定逻辑

| 输入条件 | 置信度 | 输出行为 |
|---|---|---|
| keyword 明确、模式可判（A–E 之一） | 高 | 直接检索并呈现 |
| 仅 keyword，场景或分类缺失 | 中 | 检索并呈现，推荐理由标注「基于关键词推断」 |
| 仅泛指词（「这个」「那个」「帮我弄一下」） | 低 | 提问补齐意图，不生成候选 |

## 禁止行为

- 不猜测技能功能细节
- 不虚构安装步骤与结果
- 不承诺安装后效果
- 不用「大概」「应该」糊弄确缺的信息——要么标 `[需核实]`，要么问
