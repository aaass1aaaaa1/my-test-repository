# skill-discovery-hub · 技能发现与安装中枢

> 技能市场里的一站式「找 → 挑 → 装 → 评」入口。输入一句需求，输出候选清单与推荐理由，经用户确认后完成安装。

## 解决什么问题

技能市场里技能成百上千，用户面临三个断层：**找不到**（不知道有没有现成技能）、**挑不准**（多个候选功能重叠）、**装不好**（装了跑不起来，或同域多技能互相抢触发）。本技能把「检索 → 选型 → 查重 → 安装 → 汇报」压缩成一条确定性工作流。

## 核心能力

| 能力 | 说明 |
|---|---|
| 多路检索 | 关键词数组单次调用，中英扩展、近义补充，命中合并去重 |
| 五种模式 | 纯关键词 / 分类浏览 / 组合检索 / 推荐选型 / 需求询问（「如何做 X」） |
| 选型把关 | 六维质量标准打分 + 装前查重（已装技能优先复用，不诱导全装） |
| 安全安装 | 安装需明确确认；凭证逐字复制自最新检索；结果逐项如实汇报 |
| 置信度门控 | 信息不足时标 `[需核实]` 或提问补齐，不编造 |

## 快速开始

```
用户：找个处理 PDF 的技能
技能：检索 → 输出候选表格（名称 / 说明 / 推荐理由）→ 询问装哪个
用户：装第 1 个
技能：重新搜索取凭证 → install → 汇报「已安装：PDF 工具箱（v1.2.0）」
```

## 工作流（7 步）

1. **解析意图**——抽取 keyword / tag，判定 A–E 模式，拿不准就问一次
2. **扩展关键词**——中英各备一版，最多 4–5 个查询词，不堆砌
3. **检索并合并**——关键词数组单次传入，禁止并发调用
4. **排序与呈现**——display_name + 一句话描述 + 推荐理由；零命中给近义建议
5. **选型把关**——`skill_management` 查重，六维质量标准裁决重叠候选
6. **安装落地**——确认后执行，凭证逐字复制，双路径（`name` / `skillId`）
7. **汇报**——结论先行，装了几个、跳过几个、失败几个，各自原因
